# ATPI Webpage

A responsive single-page personal site I built for my sister to present her ATPI work and profile. Plain HTML, CSS and JavaScript, no build step.

- `index.html` page structure
- `style.css` styling and responsive layout (phones, tablets, laptops)
- `app.js` interactivity

To run it, clone the repo and open `index.html` in any browser. Edit the three files to change text, colours or layout.
