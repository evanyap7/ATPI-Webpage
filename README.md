# ATPI Webpage

A simple, responsive personal webpage built for my sister to showcase her ATPI-related work, achievements, and contact information.

## Features

- Clean single-page layout focused on her profile and key information
- Separate HTML, CSS, and JavaScript files for structure, styling, and interactivity
- Mobile-friendly design that works across phones, tablets, and laptops
- Easy to extend with new sections (projects, awards, portfolio pieces)

## Tech Stack

- HTML for page structure
- CSS for styling and layout
- JavaScript (app.js) for interactive behaviour

## Project Structure

- index.html - main page markup
- style.css - page styling
- app.js - interactivity/scripts

## Getting Started

1. Clone the repository
2. Open index.html in any browser to view the webpage
3. Edit the HTML/CSS/JS files to update text, colors, or layout

## Motivation

Built this webpage as a small personal project to help my sister present her ATPI work and profile in a polished, accessible way, while practicing front-end development fundamentals.
